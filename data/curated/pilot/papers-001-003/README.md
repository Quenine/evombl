# Papers 001–003 manual-curation pilot

This directory contains 142 manually supplied observations. Paper 1 Table 2, Paper 2 Tables 3
and 4, and Paper 3 Table 3 are completely transcribed; other paper tables remain incomplete.
Empty fields remain null and no values are inferred.

Republished prior-study values are explicitly flagged and must not be treated as independent
experiments. Protein identities and mutation numbering remain paper-reported and unverified.
Modelling is not authorised and no hit or lead claims are permitted.
