# Papers 001–003 manual-curation pilot

This directory contains 109 manually supplied observations. Paper 1 Table 2 and Paper 2 Table 3
are completely transcribed; Papers 1–3 remain otherwise incomplete. Empty fields remain null and
no values are inferred.

for modelling and no hit or lead claims are permitted.
