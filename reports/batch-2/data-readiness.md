# Data readiness

The schema is ready for bibliographic metadata and identity candidates, but not for unreviewed scientific assertions. Numerical activity curation has not begun. All eleven panel identities remain unresolved pending concordant authoritative records and primary-publication review.

No hit, lead, or candidate has been identified. Metadata is not equivalent to scientific verification. Batch 2B establishes evidence persistence and audit behavior only; variant identities remain unresolved unless they later pass the documented evidence standard.

No genuine numerical activity data have been curated. Infrastructure validation uses only unmistakably labelled SYNTHETIC_TEST_DATA records.

## Readiness by stage

| Area | Status | Basis |
|---|---|---|
| Metadata retrieval | ready | Exactly-once retrieval events, immutable captures, offline reuse, controlled retries |
| Source revision | ready | Changed captures create transactional predecessor-linked revisions |
| Variant candidates | ready | Typed sequence, accession, link, mutation, numbering, structure, and chain repositories |
| Numerical bioactivity | not ready | Genuine activity ingestion and exhaustive analytical-view tests are deferred |
| Modelling | not ready | No curated activity evidence or validated modelling dataset exists |
| Experimental data | not ready | Experimental-batch and signed-report workflows remain deferred |
